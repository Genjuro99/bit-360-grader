# BIT360 Public Grader v1.0.1 - Accessibility Patch

## Scope

This local candidate changes accessibility semantics only. It does not change scoring, questions, weights, visual layout, the Acuity URL, dependencies, or public/private product boundaries.

## Changes

- Connected the Restaurant Name label to its input.
- Gave each question a stable accessible identifier.
- Connected both numeric answer fields to their question text.
- Identified each Yes, Partially, and No answer set as a radio group.
- Added question-specific accessible names and selected-state information to answer buttons.
- Added live progress text and progress-bar semantics.

## Release status

Local candidate only. Not published or deployed.
